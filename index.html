물리 모델 · 위상과 원편광 부호 · 주요 각도 비교

시간·좌표 관례
+z 진행, H = +x, V = +y. 실수 전기장은 E(z,t) = Re[J exp(i(kz−ωt))]. θ는 x→y 방향으로 잰 Fast Axis의 각도입니다. 3D 그림은 전기장 E를 나타내며 B는 표시하지 않습니다.

Jones 모델
f = (cosθ, sinθ), q = (−sinθ, cosθ).
J_QWP = ffᵀ + iqqᵀ, J_in = (1,0)ᵀ.
J_out = (cos²θ + i sin²θ, sinθ cosθ(1−i))ᵀ.

부호 일관성
s₁ = (|Eₓ|²−|Eᵧ|²)/S₀, s₂ = 2 Re(Eₓ*Eᵧ)/S₀, s₃ = 2 Im(Eₓ*Eᵧ)/S₀. 따라서 (1,+i)/√2는 s₃=+1, (1,−i)/√2는 s₃=−1입니다. 기존 QNL 코드의 부호와 같습니다. R/L 명칭은 분야마다 달라 여기서는 ±s₃로 표시합니다.

θ=45°에 H를 입사시키면 출력은 s₃=−1입니다. 계산기의 d(45°)는 입사 상태의 s₃를 측정하므로 이 두 값은 서로 다른 대상을 가리킵니다.

θ₀ = 0°는 초기값입니다. 실제 실험에서는 보정된 Fast Axis ∥ H의 다이얼각을 아래 설정에 입력하세요.
자동 저장 준비
측정 보정 · θ₀, 포트 매핑, 검출 효율, 부호

θ = 실제 다이얼각 − θ₀. 기본 카드는 θ₀+0°, +22.5°, +45°, +67.5°를 자동 표시합니다(360° 래핑). η는 양수인 상대 응답이며 보정 파워는 P/η입니다. 단위 변경 시 기존 수치도 환산합니다. θ₀는 실측 보정값이어야 하며 19°, 63°, 148° 등을 자동 가정하지 않습니다.

계산식 · 결과 해석 · CSV 안내

각도별 d = (P_H−P_V)/(P_H+P_V). QNL 기준에서는 d(θ) = cos²(2θ)s₁ + ½sin(4θ)s₂ + sin(2θ)s₃입니다. 반대 부호를 선택하면 마지막 항이 −sin(2θ)s₃가 됩니다.

기본 4각도에서는 s₁=d(0°), s₂=d(22.5°)−d(67.5°), s₃=d(45°). 최소제곱은 전체 유효 행을 동일 가중치로 맞춥니다. 순위가 부족하거나 조건수가 10⁶보다 크면 계산하지 않습니다. 조건수 100 초과는 민감도 경고를 표시합니다.

S₀는 보정된 두 포트 합의 측정각별 평균, Sᵢ=S₀sᵢ입니다. 절대 입사 파워로 해석하려면 검출 효율과 전체 손실의 절대 보정이 필요합니다. 포트 합의 변동이 커도 정규화 벡터는 추정할 수 있지만 단일 S₀의 의미는 약해집니다.

DOP=√(s₁²+s₂²+s₃²). 측정 오차로 DOP>1이 나와도 임의로 1로 제한하지 않습니다. 분류 허용오차는 0.02이며 계측 불확도 추정은 아닙니다. 부분 편광의 타원은 편광 성분만을 정규화한 궤적입니다. 무편광 성분은 단일 Jones 벡터로 표현할 수 없습니다.

CSV는 이 앱의 형식(qwp-lab-v1)으로 설정과 빈 입력을 함께 보존합니다. kind=base의 relative_deg는 0,22.5,45,67.5이며 dial_deg는 θ₀로 자동 계산됩니다. kind=extra는 실제 dial_deg를 사용합니다. 수동 편집 시 쉼표 구분, 소수점은 마침표를 사용하세요. 이 앱은 측정 데이터를 전송하는 네트워크 요청을 하지 않습니다. 3D 라이브러리만 CDN에서 불러옵니다.
